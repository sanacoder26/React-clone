⚛️ React Core Concepts & Mini React Clone
 Overview

This project is a modern React.js application built to demonstrate core React concepts such as State, Props, JSX, Reconciliation, and Single Page Application (SPA) behavior.

It also includes a mini React clone concept to give a basic idea of how React works behind the scenes.

🛠️ Tech Stack
React.js
JavaScript (ES6+)
React Router
CSS
📂 Project Structure
src/
├── components/     # Reusable UI components (Header, Footer, Card, Button)
├── pages/          # Pages (Home, About, Dashboard)
├── hooks/          # Custom hooks
├── context/        # Global state (Context API)
├── utils/          # Helper functions
├── App.jsx         # Main App component
└── main.jsx        # Entry point
✨ Features
⚛️ JSX Rendering
Clean and dynamic UI with conditional rendering
🔄 State Management
Using useState and useReducer for handling data
🔗 Props
Passing data between components for reusability
⚡ Reconciliation
Efficient UI updates using Virtual DOM & keys
🌐 SPA (Single Page Application)
Smooth navigation using React Router (no reload)
🧠 Mini React Clone
Basic simulation of component rendering and update logic

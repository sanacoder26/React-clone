## 📌 Overview

This project is a modern **React.js application** built to demonstrate core concepts:

* State
* Props
* JSX
* Reconciliation
* Single Page Application (SPA)

It also includes a **mini React clone** to understand how React works internal



---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* React Router
* CSS

---

## 📂 Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/          # App pages
├── hooks/          # Custom hooks
├── context/        # Global state
├── utils/          # Helper functions
├── App.jsx         # Main component
└── main.jsx        # Entry point
```

## ✨ Features

### ⚛️ JSX Rendering

* Dynamic UI
* Conditional rendering

### 🔄 State Management

* useState & useReducer

### 🔗 Props

* Component communication
* Reusability

### ⚡ Reconciliation

* Virtual DOM updates
* Optimized rendering

### 🌐 SPA

* React Router navigation
* No page reload

### 🧠 Mini React Clone

* Basic rendering system
* Update mechanism
